## Speech and scheduling evidence

The accepted [CPU/WebGPU comparison](../performance/2026-11-03/README.md)
qualifies the existing production model/runtime on the tested M3 Max and OS
build. It does not qualify other hardware or OS builds. Neither experimental
native candidate was promoted. Thread defaults and the production model and
native runtime pins remain unchanged.

The [app replay report](../performance/2026-11-03/recording-stop/README.md)
retains baseline, first-fix, and repeated-fix results from clean source
checkpoints before the metadata bump. Each phase contains 120 observations.
All 120 before/after pairs preserve final text. The repeated fix checks the
actual backend after every trial. The queued Swedish CPU preview case fell
from 1.325 s to 0.991 s median; other CPU cases were effectively unchanged.
This is diagnostic five-trial evidence, not a general performance guarantee.
The unchanged 600 ms drain is included.

The replay uses attributed public fixtures, temporary data, the normal Stop
handler, queues, processing, history, and published app state. As requested,
it uses no physical microphone test. It does not test device capture, paste,
LLM output, or compositor timing. An already running native inference call
can finish after Stop; the fix discards its stale result and prevents optional
work from queuing behind required transcription.

## Unverified acceptance checks

- Actual macOS 14 runtime remains unavailable. Deployment targets do not prove
  runtime compatibility, and the hosted macOS 14 image has retired.
- Installed-update permissions, live microphone/system-audio capture,
  pause/resume, and paste have not been checked for this candidate. The user's
  positive 0.7.1 manual check is historical evidence for that release.
- Configured live LLM providers and live YouTube downloads were not tested.
  The earlier YouTube check met a bot restriction.
- The app remains ad-hoc signed and is not notarized by Apple.

The user explicitly approved publication of 0.7.2 with these gaps on
4 November 2026. That exception permits publication; it does not mark these
checks as passed or the release as fully qualified. The exception is recorded
in the annotated tag and the public release notes.
