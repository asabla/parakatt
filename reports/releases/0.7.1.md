- Installed-update permissions: test live microphone, Accessibility/paste, and system audio after replacing the existing app. The launcher executable matches and microphone authorization remains authorized, but neither proves all live permission behavior.
- Live microphone and system-audio capture, pause/resume, and recording controls.
- Complete synthetic responses from configured live LLM providers. The local Ollama and LM Studio endpoints were unreachable; no OpenAI or Anthropic model or credential reference was configured.
- Live YouTube downloads: the current host received YouTube's bot check. No authentication workaround was used.

These pending checks must remain visible. The candidate is not fully qualified while required acceptance is incomplete. Follow [the release process](../../docs/releasing.md) before publication.
